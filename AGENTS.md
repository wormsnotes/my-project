# Инструкции для ИИ-агента

## Назначение и границы

Учебный проект на C++17: моделирование долларовой стоимости портфеля из RUB, USD и EUR и однодневного валютного риска. Данные синтетические: 252 торговых дня и начальная цена. Генерация траекторий использует QuantLib. Акции и облигации добавляются только по отдельному заданию пользователя.

Все файлы проекта создавай внутри `my-project`. Не меняй настройки вне проекта и подключение Git без необходимости для явно поставленной задачи. Не публикуй секреты, ключи и персональные финансовые данные.

## Структура

- `include/portfolio/portfolio.hpp`: публичные структуры и функции, документация Doxygen.
- `src/portfolio.cpp`: история, калибровка, прогноз, гипотеза, CSV.
- `src/main.cpp`: ввод и отчёт.
- `tests/`: GoogleTest и проверки CLI через CTest.
- `benchmarks/`: Google Benchmark.
- `docs/`: описание модели и конфигурация Doxygen.
- `.github/workflows/ci.yml`: сборка, тесты, бенчмарк, документация и Pages.

## Проверки перед завершением

Работай в Ubuntu/WSL из корня проекта. Используй установленные зависимости: QuantLib, GoogleTest, Google Benchmark и Doxygen. Не скачивай библиотеки во время сборки.

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
./build/portfolio-risk --rub 100000 --usd 1000 --eur 500 --samples 10000
./build/portfolio_benchmark
cmake --build build --target docs
```

Проверяй изменённое поведение и сообщай о реально выполненных проверках. Не утверждай, что CI/CD или публикация прошли, пока не проверены соответствующий запуск и сайт. После изменений расчётов нужны содержательные тесты, а не копирование алгоритма в тест.

## Правила кода и модели

- Четыре пробела для отступов, UTF-8, LF. Функции и переменные — `snake_case`, типы — `PascalCase`.
- Разделяй расчёты и консольный ввод-вывод.
- Сохраняй понятную реализацию; используй стандартные контейнеры и RAII.
- Проверяй суммы, цены, NaN, бесконечность, размеры выборок и seed.
- Все цены и итоговая стоимость выражаются в USD; цена USD равна 1.
- Seed истории фиксирован; seed прогноза и bootstrap — отдельные потоки. Seed 0 означает автоматическое зерно QuantLib и запрещён для воспроизводимости.
- Не называй синтетические данные настоящими котировками и не обещай точный прогноз рынка.
- Разделяй проверку среднего, вероятность отдельного убытка и модельный интервал.
- H0 проверяй по исходным историческим доходностям под явно заданной нулевой моделью. Число искусственных сценариев не является числом исторических наблюдений.
- Не меняй CI/CD и модельные допущения без запроса пользователя. Обновляй README и описание модели при изменении интерфейса или расчётов.
- Сборки, CSV-выгрузки, отчёты и HTML держи в игнорируемой папке `build/`.
