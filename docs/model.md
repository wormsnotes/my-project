# Модель и проверка гипотезы

## Данные и стоимость

Одна единица времени отчёта — следующий торговый день. Учебный год содержит 252 торговых дня: история содержит 253 цены, включая начальную.

Обозначения: `R_t` — USD за один RUB, `E_t` — USD за один EUR; `q_R`, `q_D`, `q_E` — количества валют. Цена одного доллара равна 1.

```text
V_t = q_R * R_t + q_D + q_E * E_t
```

Количество валют не меняется. Заёмные позиции, проценты на остатки, комиссии и налоги в первую версию не входят.

## Синтетический год

Начальные учебные цены: 1 RUB = 0.01 USD, 1 EUR = 1.10 USD. Это выбранные параметры примера, а не текущие котировки.

Для генерации используются дневные логарифмические средние -0.00010 и 0.00005, годовые волатильности 20% и 10% и корреляция 0.25. Seed истории: 2026. Эти величины не являются оценками реального рынка.

После генерации программа заново оценивает параметры по полученным дневным изменениям. Будущие сценарии не используются при оценке параметров.

## Однодневные сценарии

По дневным логарифмам изменения цен вычисляются выборочные средние `m_R`, `m_E`, несмещённые выборочные дисперсии и корреляция. Модель следующего дня:

```text
log(R_next / R_today) = m_R + s_R * Z_R
log(E_next / E_today) = m_E + s_E * Z_E
```

`Z_R` и `Z_E` — стандартные нормальные величины с оценённой корреляцией. Экспоненциальная форма сохраняет положительность цен.

Используются готовые `QuantLib::BlackScholesProcess`, `StochasticProcessArray` и `MultiPathGenerator`. Для них дневные параметры переводятся в годовые:

```text
volatility_annual = s * sqrt(252)
drift_annual = 252 * (m + s*s/2)
horizon = 1/252
```

Параметр `riskFreeTS` класса библиотеки здесь технически задаёт оценённый drift. Он не является рыночной безрисковой ставкой: моделируется физическое распределение доходностей денежных позиций, а не риск-нейтральная оценка производных инструментов.

Для каждого сценария пересчитывается стоимость портфеля. Средняя стоимость, медиана, квантили и вероятность убытка оцениваются по этим сценариям. Это условный прогноз при фиксированных параметрах. Неопределённость самих параметров дополнительно не моделируется.

## Отдельная проверка гипотезы

Равенство конкретного завтрашнего курса сегодняшнему отличается от равенства ожидаемого изменения нулю. Проверяются согласованные гипотезы:

```text
H0: E[V_next - V_today] = 0
H1: E[V_next - V_today] < 0
```

Для проверки берутся текущие долларовые веса валют:

```text
w_R = q_R * R_today / V_today
w_E = q_E * E_today / V_today
r_t = w_R * (R_t / R_(t-1) - 1) + w_E * (E_t / E_(t-1) - 1)
```

Исторические доходности вычисляются с одними и теми же сегодняшними весами. Это оценка распределения следующей дневной доходности для текущего состава, а не бэктест портфеля с неизменным количеством валют за весь прошлый год. Долларовая часть имеет нулевую доходность в USD.

Статистика проверки — историческое среднее `r_bar`. Алгоритм:

1. Вычесть `r_bar` из каждой исторической доходности: полученная эмпирическая модель удовлетворяет H0.
2. С генератором QuantLib многократно выбирать с возвращением по 252 центрированных доходности и вычислять среднее каждой выборки.
3. Посчитать число средних не выше наблюдаемого `r_bar`.
4. Оценить левосторонний `p-value = (count + 1) / (samples + 1)`.
5. Отвергнуть H0 в пользу H1 при `p-value < alpha`.

Это приближённая непараметрическая bootstrap-проверка среднего при предположении независимости и одинакового распределения дневных доходностей. Прогноз использует параметрическую логнормальную модель; проверка — эмпирические арифметические доходности. Их оценки среднего не обязаны совпадать точно.

Стабильность распределения и достаточная длина истории важны для переноса проверки на следующий день. Для реальных данных эти допущения потребуется проверять. Нулевая гипотеза о среднем допускает как положительные, так и отрицательные отдельные исходы. Неотвержение H0 не доказывает отсутствие завтрашнего движения.

История содержит 252 дневные доходности независимо от числа сценариев. Сценарии улучшают численную точность и не заменяют исходные данные. Seed прогноза, bootstrap и истории разделены.
